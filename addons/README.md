# 可选增强服务

本目录只管理本项目维护的独立增强服务。不包含聊天 UI、模型推理服务、SearXNG 源码或动态插件市场。

| 服务 | 用途 | 运行依赖 |
| --- | --- | --- |
| [web-reader](web-reader/README.md) | 公开网页 → 提取正文、日期与读取状态 | CPU、外网访问；不需要模型、embedding 或 Qdrant |

统一部署见 [deploy/README.md](../deploy/README.md)。已有 SearXNG 时只启用 `reader`；没有时可以同时启用 `search`，后者直接使用官方镜像。

## 维护约定

- 自研服务的源码、Dockerfile、固定依赖、接口说明、离线测试随仓库发布。
- 实际 `.env`、密钥、下载正文、缓存和日志不提交；构建上下文不得包含这些文件。
- HTTP 接口使用路径版本；破坏性变更新增主版本，不静默修改旧接口含义。
- 一个服务只负责一种能力。后端通过 HTTP 适配，服务不能反向导入整个后端。
- 更新依赖/镜像时跑服务测试、后端接入回归和显式真实抓取；健康检查不代表外网可达。
- 未启用增强保持原有功能；增强失败报告状态并按既定策略降级，不伪装成功。
