## 收尾补修验收（本轮）

生产改动仅涉及扩展的 runner、controller、background 和 sidepanel：

- 启动先进行只读协议探测；探测失败不占用标签、不创建后端取消会话。启动确认丢失、动作确认丢失、资源清理失败分别展示，不再全部误报“旧动作未知”。
- 动作发送前登记未确认状态，只有已结束的结果才能清除。通信失败不能证明请求未送达。
- 结束请求保存关闭意图；原始指令迟到结束后自动收尾。清理沿用同标签串行队列，多次结束不重复清理，旧会话不清理新会话。
- 清理前持久化 closing，清理与终态写入都成功才标记 ended；失败不释放占用。再次启动会先重试同一旧会话的已知安全清理，后台重启遗留 closing 则明确阻止继续。
- 原生选择检查目标选项和禁用状态，设置后回读；清空检查目标、可编辑状态并回读。找不到目标、回读不符均返回失败。普通输入的预清空失败时不再继续输入。
- 页面业务是否完成仍依赖后续新观察；不将浏览器回调完成等同于业务成功。真正未知的输入/释放失败依然禁止继续，不按时间强行解锁。

1. 点击实际侧边栏页面的发送按钮，经扩展消息、HTTP agent 路由与真实循环，完成点击、输入、选择、清空及收尾。
2. 正常收尾后同标签页再次启动，实际点击计数正确。

4. 模拟旧后台无回复：提示重新加载扩展，没有页面动作和后端请求，不虚报旧动作锁定。

8. 真实 input / textarea / contenteditable 清空及空值无操作、禁用选项、目标移除边界。

## 行为与范围

- 观察失败进入自动恢复，重新采集成功后继续；不进入人工暂停，不沿用旧截图 / 编号，不重复上一动作。预算耗尽时明确结束失败。
- 任务绑定启动时的标签页。观察带 `observation_id` 和文档 loader 身份，动作绑定 `action_id`；同 URL 重载也会拒绝旧动作。
- 单标签页只容纳一个未结束动作，同 ID 的重复投递只复用原执行。状态为未派发、部分执行、完成或未知；完成只表示执行器结束，不代表网页业务成功。
- 原始 CDP 回调未结束时不释放执行占用。内部命令等待超时也会阻止同一动作继续派发普通输入；释放按键 / 鼠标仍允许执行。
- 停止立即阻止后续派发；已发出的命令可能完成，不承诺回滚。输入或释放结果未知时阻止新输入，不自动重试。
- 后端使用协议 v2、请求摘要校验、决策查询和取消终态保护。重复请求不增加步骤；取消期间的模型迟到结果不发布。模型调用与可选摘要共用剩余决策预算和取消信号。
- 扩展后台重启后如果执行记录仍是 running/unknown，不把旧动作当作未执行。旧任务收尾不清理其他任务的标签页占用。

前端控制协调位于 `extension/agent_runner.js`，后台占用 / 去重位于 `extension/agent_execution.js`；实际观察、输入仍使用 `background.js` 的生产 CDP 路径，没有针对特定网站的分支。

## 协议与默认预算

`/v1/agent/execute`、`/step` 要求 `protocol_version=2`、`session_id`、`request_id`、`budget_ms` 和带版本的 `page_state`；`/step` 还要求匹配当前动作的 `action_result.action_id` 及已结束的 `execution_state`。未知、旧动作或同一旧观察不能推进。

`/status` 按 `session_id` + `request_id` 返回原决策结果或 processing；请求尚未收到时才允许使用原 ID 和原请求体重投，不另起决策。

| 阶段 | 默认预算 |
| --- | --- |
| 单次观察 / 一次观察恢复阶段 | 30 秒 / 90 秒，恢复间隔逐步增加至 4 秒 |
| 单动作 / 超时后的结束确认 | 120 秒 / 30 秒 |
| 后端一次决策 | 180 秒；单次模型调用最多 90 秒且受剩余预算限制 |
| 整个任务 | 1 小时；清理阶段另有有界等待 |

原始命令超过预算仍未确认时不会为了符合时限而虚假释放占用。终止信息保留该区别。

## 验收边界与启用

- 真实浏览器验收测试的是观察 / 执行控制；不是真实模型—后端—扩展 UI 的全链路验收。后端采用隔离 FastAPI TestClient 和可控模型响应，前端循环使用实际函数配测试替身。
- 未访问真实模型、远端 Qdrant / reranker，未操作生产知识库或业务数据。
- 仍限单后端进程与有效会话保留期；不提供跨后端重启、多 worker 或任意网页事务的 exactly-once 保证。
- 不新增视觉坐标、拖拽、验证码或人工接管功能。
- 启用时需重启后端，并在扩展管理页重新加载当前扩展，再关闭重开侧边栏。仅重启后端或仅刷新网页不够。
- 若动作结果永久未知，先检查业务结果；关闭该测试标签后重新打开，再决定是否重试，不能盲目重复提交。
